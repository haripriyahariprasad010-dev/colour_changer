🎨 Color Picker

A simple, aesthetic Color Picker built using HTML and CSS, with a little JavaScript to make it interactive.

This project lets users select a color and instantly see the webpage background change to match their choice. It also displays the selected HEX color code, making it easy to identify and reuse colors in other designs.

I created this project to practise frontend development and explore how a small interactive tool can be built with a clean and minimal interface.

✨ Features

Choose any color using the built-in color picker.

Instantly change the webpage background.

Display the selected HEX color code.

Minimal and responsive design.

Smooth color transitions.

🛠️ Technologies Used

HTML5 – Structure of the webpage.

CSS3 – Styling, layout and responsive design.

JavaScript – Updating the background color and HEX code dynamically.
